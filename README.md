## Como editar este site

- O site está em HTML/CSS simples — arquivos principais: `index.html` e `styles.css`.
- Para atualizar textos, abra `index.html` e altere os campos desejados.
- Para trocar o avatar ou logos, coloque imagens na pasta `assets/`.
